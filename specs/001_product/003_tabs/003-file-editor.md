# File Editor 用户行为规范

状态：Draft

版本：V1

## 1. 用户目标

用户在 CCSM2 内编辑和预览 Markdown，并完成文本文件的查看、小范围编辑和显式保存。编辑状态、保存结果和文件冲突均具有清晰反馈。

## 2. V1 范围

包含：

- 从 File Explorer 打开文件
- 文本编辑与语法高亮
- Markdown 内容预览
- Markdown 编辑/预览模式切换
- 文件内查找与替换
- 撤销与重做
- 显式保存
- 未保存状态提示
- 关闭确认
- 外部文件变更检测
- 文件 Tab 恢复

不包含：

- 自动保存
- Save As
- 跳转定义与查找引用
- Language Server
- Minimap
- Diff Review
- 二进制文件编辑
- 崩溃后的未保存内容恢复

## 3. 打开文件

- 单击 File Explorer 中的文件时，File Editor Tab 打开。
- 同一路径已经存在对应 Tab 时，已有 Tab 获得焦点。
- 同一路径在同一 Workspace 内仅对应一个 File Editor Tab。
- Tab 标题显示文件名。
- 存在同名文件时，标题附带最短可区分父目录。
- Tab Tooltip 显示 Workspace 相对路径。
- 文件加载期间展示 Loading 状态。
- 文件加载失败时，Tab 保持打开并展示错误信息。
- 文件成功加载后，焦点进入内容区域。
- Tab 再次获得焦点时，光标和滚动位置保持不变。

V1 中的 File Editor Tab 均为普通持久 Tab，不区分 Preview Tab。

## 4. 编辑体验

普通文本编辑区域包含：

- 行号
- 当前行高亮
- 语法高亮
- 括号匹配
- 自动缩进
- 撤销与重做
- 文件内查找
- 文件内替换
- 跳转到指定行
- 中文及其他 IME 输入
- 光标行列信息
- 自动换行开关

自动换行默认关闭，并按 Tab 保存当前会话状态。

语言类型根据文件扩展名识别。无法识别的文件按纯文本显示。

`.md`和`.markdown`文件提供Edit与Preview模式。首次打开进入Preview；用户选择的模式按Tab保存。Edit模式复用普通文本文件的CodeMirror编辑体验和保存流程。

Preview模式由markdown-it渲染当前编辑内容，包含：

- 标题、强调、链接、引用和列表
- 围栏代码块和行内代码
- 表格与删除线
- 自动链接

Preview中的原始HTML按文本展示。相对链接与`http`、`https`、`mailto`链接在独立浏览上下文中打开；图片显示替代文本，打开预览不会加载图片地址。预览样式使用应用CSS变量，并跟随深浅模式。

## 5. 编辑状态

| 状态      | 用户可见表现                       |
| --------- | ---------------------------------- |
| Loading   | 编辑区域显示加载状态               |
| Clean     | Tab 不显示修改标识                 |
| Dirty     | Tab 显示未保存标识                 |
| Saving    | 保存操作显示进行中状态             |
| Conflict  | 编辑区域显示外部变更提示           |
| Read-only | 编辑操作关闭并显示原因             |
| Error     | 显示错误信息，本地编辑内容保持不变 |

文本内容首次发生变化时，状态从 Clean 转为 Dirty。

撤销至磁盘版本时，状态恢复为 Clean。

Markdown Tab使用完整文件编辑状态。切换到Preview时渲染当前内存文本；Clean状态接收磁盘变化后，编辑文档和预览同步刷新。

## 6. 保存

可编辑文本文件的保存入口包含：

- 编辑器工具栏中的 Save 操作
- Ctrl+S
- macOS 下的 Cmd+S

保存流程：

1. Dirty 状态进入 Saving。
2. 保存成功后进入 Clean。
3. Tab 中的未保存标识消失。
4. 界面短暂显示 Saved。
5. 保存失败后返回 Dirty。
6. 错误信息显示在当前 Tab 内。

Clean 状态下触发保存时，文件写入流程不执行。

保存后的文件保持原有：

- UTF-8 BOM
- LF 或 CRLF 换行格式
- 文件末尾换行状态

## 7. 关闭

Clean 状态的 Tab 直接关闭。

Dirty 状态的 Tab 展示确认窗口：

> Save changes to {fileName}?

操作项：

- Save：保存成功后关闭
- Discard：放弃本地修改并关闭
- Cancel：返回编辑状态

保存失败时，Tab 保持打开。

应用或 Workspace 关闭期间存在多个 Dirty Tab 时，确认窗口展示文件列表，并提供：

- Save All
- Discard All
- Cancel

部分文件保存失败时，失败文件保持打开并显示对应错误。

## 8. 外部文件变更

### 8.1 Clean 状态

磁盘文件发生变化时：

- 编辑器加载磁盘最新内容。
- 光标和滚动位置尽量保持。
- 界面显示 File changed on disk。
- 撤销历史基于重新加载后的内容重新建立。

### 8.2 Dirty 状态

磁盘文件发生变化时：

- 本地编辑内容保持不变。
- 文件进入 Conflict 状态。
- 保存操作展示冲突确认窗口。

冲突操作项：

- Overwrite：使用编辑器内容覆盖磁盘版本
- Reload from Disk：放弃本地内容并加载磁盘版本
- Cancel：返回当前编辑状态

Diff Review 上线后，冲突窗口增加 Compare 入口。

### 8.3 文件被删除

Clean 状态下文件被删除时，编辑器进入 Read-only 状态并显示：

> File no longer exists on disk.

Dirty 状态下文件被删除时，编辑器保留本地内容并进入 Conflict 状态。保存操作提供重新创建文件的明确确认。

### 8.4 文件权限变化

文件失去写入权限时，编辑器进入 Read-only 状态并显示权限原因。

## 9. 文件格式与大小

| 文件类型                         | 行为                       |
| -------------------------------- | -------------------------- |
| Markdown，≤ 5 MiB                | 编辑与预览                 |
| 其他 UTF-8 / UTF-8 BOM，≤ 1 MiB  | 编辑与语法高亮             |
| 其他 UTF-8 / UTF-8 BOM，1～5 MiB | 编辑、纯文本显示、性能提示 |
| 超过 5 MiB                       | 展示文件过大提示           |
| 二进制文件                       | 展示格式提示               |
| 非 UTF-8 文件                    | 展示编码提示               |
| 未知扩展名                       | 纯文本编辑                 |

文件大小阈值在性能验证后进入正式基线。

## 10. 会话恢复

正常重启后：

- 已打开的 File Editor Tab 恢复。
- 文件内容从磁盘重新读取。
- 光标和滚动位置尽量恢复。
- Markdown Edit/Preview模式恢复。
- Tab 顺序恢复。
- Dirty Tab 在正常退出流程中完成保存确认。

进程崩溃或强制终止后的未保存内容恢复不属于 V1。

| ------ | ------------- | ------------ |
| 保存   | Ctrl+S        | Cmd+S        |
| 查找   | Ctrl+F        | Cmd+F        |

## 12. 验收场景

### 打开去重

- 同一文件连续点击两次后仅存在一个 Editor Tab。
- 第二次点击后已有 Tab 获得焦点。

### 编辑保存

- 修改内容后 Tab 显示未保存标识。
- 保存成功后磁盘内容更新，未保存标识消失。

### Markdown预览

- 打开`.md`或`.markdown`文件后进入Preview模式。
- Edit模式能够输入内容，并产生与其他文本文件一致的Dirty和保存状态。
- 切换到Preview后，标题、列表、链接、代码块、表格和删除线按当前内存文本渲染。
- Preview中的原始HTML以文本呈现，危险协议链接不会生成可点击链接。
- Preview中的图片显示替代文本，远程与本地服务地址不会自动加载。
- 深浅主题切换后预览内容同步更新样式。
- 保存后磁盘内容与Edit模式中的文本一致。

### 关闭保护

- Dirty Tab 关闭时展示确认窗口。
- Cancel 后编辑内容保持不变。
- 保存失败后 Tab 保持打开。

### 外部冲突

### 内容完整性

- CRLF 文件保存后不会产生整文件换行 Diff。
- UTF-8 BOM 状态保持不变。
- 中文 IME 输入、撤销和保存结果正确。

### 文件限制

- 大文件不会阻塞应用主界面。
- 二进制与非 UTF-8 文件不会进入可编辑状态。
